# Skills：学习与科研提示词

整理日常使用、逐步调整的 AI 提示词、工作流程和学习笔记，覆盖讲义批注、论文收集、学者研究方向分析与科研答辩准备。

当前内容以 Markdown 文档提供，可以复制到对话中使用，也可以交给支持文件读取的 AI 助手。执行效果取决于模型、工具权限、输入资料和网站访问条件。

## 使用方法

1. 按任务选择文档，替换 `【文件路径】`、`【学者姓名】`、`【链接】`、`【输出目录】` 等占位内容。
2. 提供对应讲义、Scholar 页面或论文数据。普通聊天界面可以上传文件并粘贴提示词；支持本地文件操作的助手可以直接读取指定文档。
3. 告诉助手开始执行。需要登录、验证码或人工下载时，在指定页面完成操作后继续。
4. 检查交付结果，尤其是公式、限定条件、作者归属、论文版本，以及研究结论的证据。

例如，将提示词内容提供给助手后，可以补充：

```text
请按这份 HTML 讲义批注提示词处理我提供的讲义。
处理范围：整份讲义。
输出目录：【填写输出目录】。
批注以忠实、简短的中文复述为主，保留英文专业术语。
```

```text
请按这份论文采集提示词收集【学者姓名】在【年份范围】内的论文。
Scholar：【填写链接】。
保存目录：【填写保存目录】。
先检查已有状态，继续未完成项，最后报告覆盖情况与缺失条目。
```

## 工具与适用范围

- 讲义批注需要助手能够读取 PDF；生成 HTML 或 PDF 成品还需要相应的文件处理与代码执行工具。提示词文件本身不包含完整的阅读器程序。
- 论文收集流程使用 [agent-browser](https://github.com/vercel-labs/agent-browser) 和后台 HTTP 下载，并需要本地文件读写与 PDF 核验能力。登录状态、机构订阅及网站验证会影响可获取的内容。
- 论文收集提示词保留了 HKUST 图书馆入口和 Wiley 人工下载等个人使用约定，使用前可按自己的机构与偏好调整。
- 采集测试记录中的行为对应当时的工具版本和访问条件；阶段性的暂停、失败和数量变化按时间保留，最终结果见文末。
- 生成的批注和研究分析仍需核对；正文获取不完整时，应保留缺失说明，避免把部分材料当成完整研究记录。
