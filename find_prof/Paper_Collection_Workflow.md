# 论文采集流程

> 这是一份历史测试记录，记录 2026-11-23 对 Ruohan Gao 的论文采集与故障排查过程。文中的阶段进度按执行先后保留，最终结果见末尾；不代表每次采集都必须逐步暂停，也不保证工具行为在其他版本中相同。本机路径和会话名已替换为公开示例。

1. 使用 agent-browser 独立后台浏览器，打开学者的 Google Scholar 链接。

2. 读取页面状态，确认是否显示论文列表。Ruohan Gao 本次测试跳转至 Google `/sorry/`，显示 reCAPTCHA，尚未获取清单。

   问题：独立后台会话不共享用户日常 Chrome 的验证状态；遇到人机验证，需要用户手动完成。

3. 用户在日常 Chrome 中打开 Scholar、完成验证，并展开到出现至少一条 2023 年条目；助手使用 agent-browser 的 `--auto-connect` 连接现有 Chrome，选择对应标签页，直接读取已加载的标题和年份，不重新打开或刷新 Scholar。

   验证结果（2026-11-23，Ruohan Gao）：连接成功，2026 年 12 条、2025 年 16 条、2024 年 5 条，共 33 条；已出现 2023 年条目，本次未再次触发人机验证。这里只确认 Scholar 清单读取成功，尚未判断条目类型、去重或下载论文。

   前提：Chrome 可被 agent-browser 发现并连接；仅打开页面并不保证连接可用。本次实际命令为 `npx --yes agent-browser --session paper-collection-example --auto-connect tab`，再用 `tab t1` 选择 Scholar 标签页，并通过 `eval --stdin` 读取当前页面的 `.gsc_a_tr` 条目。

4. 整理并核实论文清单。提取目标年份的标题、作者、发表信息、年份及 Scholar 链接，保存为 Markdown 和 JSON；结合 Scholar 详情及出版来源，核对重复记录、材料类型、作者归属和版本变化。保留原始编号，疑点标记待核实，不直接删除。

   本次结果：33 条记录已保存并读取详情；S004 与 S005 重复，以 S005 为主记录；3 条他人学位论文单独列示；S013 疑似同名误收，暂缓下载。Workshop、公开投稿、期刊 Highlight 及改题版本均已注明，不能混作已录用的主会论文。

5. 准备下载入口。优先查找公开全文或作者稿，核对预览页标题、作者及版本，区分正文与补充材料，记录 PDF 链接、下载方式和英文保存文件名。后台 HTTP 访问受阻时可检查现有 Chrome；遇到需要人工验证或登录的页面，保留页面并记录暂停原因。本阶段不下载 PDF。

   判断要点：HTTP 200 可能是验证页，403/418 不能推断为没有全文；新标签页须等目标 URL 和 DOM 加载后再读取。找到预览页或 PDF 链接，不等于 PDF 已下载或完整。

   当前进度：25 条正文候选已核对预览元数据并找到 PDF 入口；S005、S031 的入口仍待核实。S021 停在日常 Chrome 的 AIP／Cloudflare 安全验证页，等待用户完成验证后继续。尚未下载或验证任何 PDF，准备工作未全部完成。逐项结果见 `<output_directory>/Download_Preparation_2024-2026.md` 及同名 JSON；详细证据保存在 `Preparation_Evidence`。

6. 单篇下载验证。先选一篇已核对预览信息的公开稿，通过后台 HTTP 下载到 `.part` 文件；检查是否为真正 PDF、下载字节数是否与服务器声明一致、结构是否可解析，并核对标题作者。验证通过后改为英文最终文件名，记录大小、页数、SHA-256 及结果；先验证一篇，再决定是否批量。

   本次结果：S001《OdorSpaces》从 arXiv 直链下载成功，4,679,193 字节、20 页；标题和 5 位作者匹配，PDF 文件头／EOF、HTTP 长度、全部页面严格解析通过，首尾页渲染及目视检查正常。首页面有字体类型提示但渲染成功，原 PDF 未改写。共下载 1 篇，未扩大数量、未操作鼠标键盘；日志保存到 `<output_directory>/Download_Log_2024-2026.md`。第 5 步的 S021 验证及 S005、S031 入口核实仍未完成。
